# Przyszłe pomiary

Obecnie brak wyników badań fizycznego prototypu. Nie ma pomiarówTS,THD,
kompresji ani odpowiedzi pokoju. Pliki w`wyniki/` są obliczeniami/symulacjami.

Dobór toru po budowie, pomiary tylko w pokoju, zgodnie z decyzją użytkownika.
Surowe pliki przechowywać w`surowe/<session_id>/` bez nadpisywania; osobno
kalibracja, ustawienia,DSP, geometria, tło, temperatura i notatki.

Użyć [szablonu](../../szablony/raport_pomiarowy.md) i
[procedur](../../baza_wiedzy/06_metrologia_i_walidacja.md). Nie tworzyć
fikcyjnych wyników ani wypełniać tabel pomiarów prognozami modelu.
