# K33 — metalowa blokada, CNC HOLD

Części robocze do odrębnej obróbki metalu. Nie zlecać jako MDF.
Wymiary mm. Brak zatwierdzonego stopu, tolerancji, gwintów i spoin.

| Plik | Znaczenie |
|---|---|
| KROTKA_OBRYS_XY_Z50_HOLD.dxf | Jeden element: poprzeczka+nos, profil XY ekstrudowany50 w Z, nasadaR4 |
| KROTKA_CZOL0_YZ_HOLD.dxf | Drugi widok tej SAMEJ części; dwa przelotyØ6 w osi X przez18 mm |
| DLUGA_CZOL0_YZ_HOLD.dxf | Poprzeczka312×50×18 z przelotamiØ6 i czterema symbolami M4 od tylnej powierzchni |
| KOLNIERZ_80x50x4_HOLD.dxf | Metalowy kołnierz z czterema przelotamiØ5 |
| K33_OBWIEDNIE_SERWISOWE.scad | Tylko obwiednie do kontroli montażu; NIE bryły produkcyjne |

**THREAD_M4_BLIND10 oznacza gwint, nie średnicę wiertła.** OkrągØ4 nie
jest torem frezowania. Gwint użyteczny10 mm; wiercenie pod gwint, wybieg
oraz głębokość technologiczna do opracowania. Kandydat śrub M4×12 bez
podkładek, łby modeloweØ8×4. Profil20×20×2 o długości295,1, zaślepka
wewnętrzna2 mm i spoina nie są zamówieniem opisanym wyłącznie DXF.

W100 używa się czterech krótkich blokad. W120 drugą zastępuje długa.
Nie pozostawiać jednocześnie starego noska MDF i nowego ogranicznika.
Płytki i wręga K32 zachowane. Starsze pliki są archiwum, nie częściami
montowanymi obok nowych. K33 nie jest pełnym zestawem CNC skrzyni.
