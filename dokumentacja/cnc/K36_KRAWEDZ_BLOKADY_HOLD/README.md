# K36 — korekta krawędzi metalowej blokady, CNC HOLD

Trzy DXF zastępują odpowiednie widoki K33. Wspólnie opisują krótką część
z integralnym noskiem (obrys XY, wysokość Z50 i otwory na widoku YZ)
oraz długą poprzeczkę (widok YZ, grubość X18).
Krawędź Y47 zamiast45, szerokość310 zamiast312; globalne osie M5 Y55/347.
Nie przesuwać noska ani kołnierza. Kołnierz K33 pozostaje bez zmiany.

Jednostki mm. Części metalowe, nie MDF. Warstwa THREAD_M4_BLIND10
jest oznaczeniem gwintu, nie średnicą wiertła. Brak zatwierdzonego stopu,
tolerancji, momentów i nośności węższej krawędzi. Nie kierować do produkcji.
Pliki nie stanowią kompletnego nowego zestawu obudowy. Geometria zależnych
prowadnic jest w JSON K36, bez wydania ich DXF i bez pomiarów materiału.
